# Security Policy

## Reporting a Vulnerability

We take security issues seriously. If you discover a security vulnerability in
**Fast News MCP**, please report it responsibly so we can fix it.

### Preferred: GitHub Private Vulnerability Reporting

Use GitHub's built-in private vulnerability reporting on the
[Security tab](https://github.com/wllrdev/Fast-News-MCP/security/advisories/new)
of this repository. Reports submitted this way are private and visible only to
the maintainers.

### Alternative: Discord

You can also reach us privately in our
[Discord](https://discord.gg/kEFfEzPqsk).

## What to Include

- A description of the vulnerability and its potential impact
- Steps to reproduce (code, configuration, or request examples)
- The affected version (see the version in `package.json` / `server.json`)
- Any suggested fix, if you have one

## Scope

This policy covers the open-source code in this repository — the MCP wrapper,
its configuration, and documentation.

It does **not** cover the underlying **Fast News with Previews API** hosted on
RapidAPI. The MIT license of this repository does not grant access to the API,
and API-side issues must be reported to RapidAPI or the API provider directly.

## Response

We aim to acknowledge reports within **72 hours** and to provide a fix or
mitigation based on severity.
